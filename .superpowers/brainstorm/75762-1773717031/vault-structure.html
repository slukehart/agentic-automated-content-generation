Vault Structure

Folder layout and ownership boundaries

vault/ — Project Root
📁 vision/ — You write
goals.md · what you're building toward
roadmap.md · phased feature plans
feature-ideas/ · one note per idea

📁 system/ — Agents write (you approve)
📁 architecture/ · how components work & connect
pipeline-overview.md · heygen-integration.md · tiktok-upload-flow.md
📁 decisions/ · why things were built this way
2026-03-16-single-llm-call-metadata.md · 2026-03-16-manifest-over-db.md
📁 lessons/ · gotchas, failures, tips
tiktok-api-quirks.md · heygen-avatar-sizing.md

📁 prompts/ — Both write
metadata-generation.md · prompt engineering notes
summary-tuning.md · what produces good summaries

📁 templates/ — Shared
architecture-note.md · frontmatter template for system/architecture/
decision-note.md · frontmatter template for system/decisions/
lesson-note.md · frontmatter template for system/lessons/

Ownership Rules

You

vision/

Goals, roadmap, feature ideas. Your intent — agents read but never modify.

AI

system/

Architecture docs, decisions, lessons learned. Agents draft, you approve before save.

Both

prompts/ & templates/

Shared space. You tune prompts, agents document what works. Templates keep notes consistent.
